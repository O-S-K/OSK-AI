# OSK-AI

## Overview
OSK-AI is an AI framework for Unity, written in C#. It provides:
- **Behavior Tree**: Modular agent decision-making.
- **FSM (Finite State Machine)**: Simple state logic.
- **HFSM (Hierarchical FSM)**: Nested state machines for complex behaviors.

## Structure
- `BehaviorTree/` — Behavior Tree implementation
- `FSM/` — Finite State Machine
- `HFSM/` — Hierarchical FSM

## Setup

### Prerequisites
- Unity (recommended 2022.3 or newer) 

### Installation
1. Clone the repository:
2. Open the project in Unity.

## Usage
- Import the `Assets/OSK-AI` folder into your Unity project.
- Use the provided AI components in your GameObjects.
- Refer to code samples in each system folder for integration.
